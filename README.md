# 🌦️ Clima Agora

Aplicação web para consulta de condições meteorológicas em tempo real e previsão para os próximos 7 dias.

O projeto foi desenvolvido com React e TypeScript, consumindo dados da API Open-Meteo e utilizando uma interface responsiva construída com SCSS.

## 🚀 Demonstração

🌐 **Acesse o projeto:**  
https://clima-dashboard-d38h.vercel.app

## ✨ Funcionalidades

- 🔎 Busca de cidades
- 🌡️ Temperatura atual
- 🌡️ Sensação térmica
- 💧 Umidade do ar
- 💨 Velocidade do vento
- 🌤️ Condição climática atual
- 📅 Previsão para os próximos 7 dias
- 🌍 Identificação do país da cidade pesquisada
- 📱 Interface responsiva
- ⚠️ Tratamento de erros e carregamento

## 💻 Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/william78dev/clima-dashboard.git
```

Entre na pasta:

```bash
cd clima-dashboard
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

A aplicação estará disponível no endereço indicado pelo Vite no terminal.

🌐 **Projeto online:** https://clima-dashboard-d38h.vercel.app

## 🌦️ API

Os dados meteorológicos são fornecidos pela Open-Meteo API.

O projeto utiliza geocodificação para localizar a cidade pesquisada e consulta dados meteorológicos atuais e previsão diária.
